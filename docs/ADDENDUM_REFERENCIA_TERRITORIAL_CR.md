**Rutas CR · Estándar de Oro Territorial (DTA 2026)**

---

## 📌 1. Origen y Propósito de este Addendum

Para garantizar que el directorio **Rutas CR** ofrezca información **100% verídica, fidedigna y libre de falsos positivos**, se incorporó como base de referencia maestra el archivo:

> **Archivo Maestro:** `ConversionReferencias_CR_AppSheet_Optimizada.xlsx`  
> **Tamaño:** ~2.9 MB  
> **Fuente Normativa:** División Territorial Administrativa (DTA 2026) oficial del SNIT / Instituto Geográfico Nacional (IGN) / INEC.

Este documento y sus bases indexadas resuelven de forma estructural el problema de los **lugares homónimos** (pueblos, caseríos y playas que comparten exactamente el mismo nombre en diferentes cantones y provincias de Costa Rica).

## 🛠️ 5. Implementación en el Código y Aplicaciones

1. **Sectorización Fidedigna por Matriz Maestra (`ZONAS_OFICIALES_TRANSPORTISTA`):**
   - La página web (`index.html`) no depende de coincidencias ingenuas de texto. Utiliza las zonas operacionales verificadas de cada transportista.
2. **Índice Ligero en JSON (`docs/homonimos_oficiales_cr.json`):**
   - Permite consultas instantáneas en el buscador web sin necesidad de procesar los 2.9 MB del Excel en el navegador del usuario.
3. **Herramienta de Auditoría en Google Sheets:**
   - La base sirve para validar automáticamente que cualquier nuevo transportista que se registre en la hoja indique el cantón correcto cuando su destino sea homónimo.
